Machine Learning Model

Information about the AR toxicity model which is used for toxicity prediction.

Overview

This web server predicts molecular toxicity directly from a SMILES string using a Quantitative Structure–Toxicity Relationship (QSTR) model. The workflow converts the molecule into molecular descriptors/fingerprints, and applies a trained machine learning model to estimate toxicity probability.
