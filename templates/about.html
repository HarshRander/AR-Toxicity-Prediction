About This Platform

An ML-assisted QSTR platform for predicting molecular toxicity from chemical structures represented as SMILES.

Project Overview

This web application provides an easy-to-use interface for predicting the toxicity of small molecules using machine learning. Users simply enter a SMILES string, and the platform validates the structure, generates molecular descriptors/fingerprints, and predicts AR toxicity using a trained QSTR model.

Besides toxicity prediction, the platform also calculates several physicochemical properties useful in drug discovery such as molecular weight, LogP, TPSA, hydrogen bond donors/acceptors, Lipinski Rule of Five evaluation, and additional structural descriptors.

Platform Features

🧬

SMILES Validation

Checks whether the submitted SMILES represents a chemically valid molecule using RDKit.

🤖

Machine Learning Prediction

Predicts molecular toxicity using a QSTR model trained on ChEMBL database data.

📊

Molecular Properties

Displays important molecular descriptors and drug-likeness properties.

Prediction Workflow

  1. Enter a SMILES string.
  2. Validate molecular structure using RDKit.
  3. Generate molecular fingerprint/descriptors.
  4. Preprocess descriptors.
  5. Apply trained QSTR model.
  6. Predict whether a molecule is toxic or not.
  7. Display molecular properties and drug-likeness.

Research Purpose

This platform demonstrates how machine learning and cheminformatics can be integrated for rapid toxicity screening of chemical compounds. Such computational approaches can help prioritize molecules before experimental validation, reducing both cost and time during early-stage drug discovery.

Disclaimer

Predictions generated by this platform are intended solely for research and educational purposes. They should not be used as a replacement for experimental validation or professional toxicological assessment.
